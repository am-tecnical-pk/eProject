APTECH ePROJECT SPECIFICATION • BIG DATA ANALYTICS

Hadoop Paradigm Replicated in Python

EduPredict addresses institutional retention challenges by applying distributed storage concepts, parallel map-reduce processing, and machine learning pipelines to academic datasets.

PROBLEM STATEMENT & MOTIVATION

Transforming Raw Academic Records into Early Interventions

Educational institutions capture vast data footprints daily—including attendance records, LMS activity scores, and continuous academic assessments. Unstructured or siloed storage prevents early identification of students trending toward academic distress.

EduPredict emulates Hadoop Distributed File System (HDFS) partitioning and MapReduce workflows in Python to efficiently clean, partition, and score large-scale learner profiles in real time.

Core Technical Pipeline

  • 01
    Data Ingestion & Chunking HDFS-style chunked batch ingestion with missing value imputation.
  • 02
    Parallel MapReduce Processing Multi-core anomaly mapping, correlation indexing, and aggregation.
  • 03
    Predictive Inference Ensemble Scikit-Learn regression and classification for risk and grade projection.
  • 04
    Alert Notification Service Automated SMTP dispatching when risk indexes exceed defined thresholds.
